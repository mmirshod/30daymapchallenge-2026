ДАННЫЕ И ПОДХОД

Как устроена работа

Асфальт, обычные дороги и треки: сравнение высоты дорожной сети по данным OpenStreetMap и Copernicus DEM.

  1. Дороги из OSM разделены на объекты с явным surface=asphalt, обычные дорожные классы без track и все потенциально проезжие классы с track. Категории пересекаются; теги доступа сохраняются для проверки.
  2. Вдоль исходных линий создаются геодезические пробы с шагом не более 30 м, включая исходные вершины геометрии. Высоты извлекаются из плиток Copernicus DEM. Туннели исключены: высота поверхности над тоннелем не равна высоте дороги.
  3. Точки пространственно связываются с районами; для каждой категории сохраняются максимумы и кандидаты для проверки. Показанные высоты — выборочные оценки нанесённых на карту дорог, а не дорожная съёмка.
Как читать результат

OSM-класс не гарантирует проезд или открытый доступ. Неполные теги покрытия, границы, мосты и разрешение DEM влияют на результат. Числа в README помечены как предварительные оценки.
